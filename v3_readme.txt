5050bot v3 by kondaira946
========================
Purpose
-------
Automates betting in the 5050 game using AutoHotkey v2.
Each bet is set to 40% of the available points using the slider.

Requirements
------------
- Windows
- AutoHotkey v2 (for the .ahk version)
- The 5050 game running in a compatible window size (tested by the user at Full HD)

How to use
----------
1. Launch 5050 and keep its window visible and active.
2. Run 5050bot_v3.1.ahk (or a compiled .exe).
3. Press F6 to place a single bet.
4. Press F7 to start automatic betting.
5. Press F7 again to pause automatic betting.
6. Press F8 to exit the bot.

Important
---------
- The bot uses the real mouse cursor and acts on the active window.
- Pause with F7 before switching to another application.
- The bot does not read your score or stop at 1,000,000 points.
- Betting outcomes are random; reaching the goal is not guaranteed.
- If window scaling or the game's layout changes, mouse coordinates may need adjustment. Restart the script

Compiling
---------
With AutoHotkey v2 and Ahk2Exe installed, right-click the .ahk file
and select Compile Script to produce a Windows executable.
